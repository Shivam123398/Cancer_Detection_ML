# Breast Tumor Detection Using Microstrip Antenna and Machine Learning

A research project exploring the use of simulated microstrip antenna S11 data and machine learning classification to distinguish between healthy breast tissue and simulated breast tumor cases.

## Project Overview

This project was developed as part of an internship at the **National Institute of Technology (NIT) Jamshedpur**.

The work combines electromagnetic antenna simulation with machine learning. S11 response data from simulated breast tissue models is processed to extract features, and multiple classification algorithms are trained and compared.

**Important:** This is an experimental, simulation-based research project. It is not a clinically validated cancer detection system and must not be used for medical diagnosis.

## Objectives

* Design and simulate a microstrip patch antenna using CST Studio Suite.
* Study S11 responses for simulated breast tissue models with and without tumors.
* Investigate simulated tumors of different diameters: 5 mm, 10 mm, and 15 mm.
* Extract features from frequency and S11 data.
* Train and compare multiple machine learning classifiers.
* Generate performance plots and save model artifacts.

## Antenna Simulation

The antenna was modeled using a 50 mm × 50 mm FR-4 substrate and simulated over a frequency range of approximately 0.3–5 GHz.

The S11 response was investigated at multiple resonant frequencies. These simulated responses were used as input data for the machine learning pipeline.

The repository's `raw_data/` folder contains the exported simulation files.

## Dataset

The dataset contains **35 simulated cases**:

* 5 no-tumor cases
* 10 cases with a 5 mm tumor
* 10 cases with a 10 mm tumor
* 10 cases with a 15 mm tumor

The `.txt` files contain frequency and S11 magnitude values. The filenames identify the corresponding simulated case.

This dataset is small and simulation-based; it does not represent a clinical patient dataset.

## Machine Learning Pipeline

The main script is `scripts/advanced_ml_pipeline.py`.

The pipeline is designed to:

1. Load the raw S11 simulation files.
2. Extract features from the simulation responses.
3. Prepare the dataset for classification.
4. Split the data into training and testing subsets.
5. Train and compare machine learning models.
6. Evaluate model performance and perform cross-validation.
7. Generate comparison plots and a CSV report.
8. Save the selected model and supporting preprocessing artifacts.

### Models Compared

The pipeline includes the following classifiers:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Decision Tree
* Random Forest
* XGBoost
* CatBoost
* Artificial Neural Network (ANN), when its optional dependency is available

## Installation

Install Python 3.11 or another Python version compatible with the required machine learning libraries.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Cancer_Detection_ML.git
cd Cancer_Detection_ML
```

Create and activate a virtual environment.

**Windows PowerShell:**

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run the Pipeline

From the repository root, run:

```bash
python scripts/advanced_ml_pipeline.py
```

The script saves model artifacts, plots, and reports to the corresponding project folders.

Some classifiers are optional in the script. If an optional library is unavailable, that model may be skipped. Check the console output and installed dependencies if a model does not run.

## Limitations

* The dataset contains only 35 simulated cases.
* There are only 5 no-tumor cases, so healthy-case performance is particularly uncertain.
* The test set contains only 7 samples; reported test metrics can change substantially with different splits.
* The results are based on simulations, not clinical measurements.
* Physical antenna measurements and validation using real patient data have not been established by this project.
* High accuracy on this small dataset does not establish clinical reliability.
